# Fractals!
(This is my first ever properly shipped independent project!
Sorry if it doesn't work that well, but it hopefully should.)
## What is it?
[Demo link!](https://hana-w24.github.io/Fractals/)
This is an interactive-ish website, made in html and CSS, within Vscode.
It is interactive, as in the title changes colour and font when you hover over it.

This started off as just an idea, both to help me understand how to fully ship a project and use vscode and github properly, but also as 'training' for an upcoming html task I need to do.
I took inspiration from 'Phantom' (what I made this for, organised by hack club), Phantom of the opera (one of my favourite musicals) and fractals, just because they seem really cool and have an interesting concept, that they can go on infinitely. 
This project was just made to help me get used to actual coding and so I spent more time focusing on how everything works rather than trying to build more on my coding skills. Hopefully I can learn more in future projects!
## How to install?
1. Go to the GitHub repository page containing the files
2. Click the green Code button near the top right of the file list
3. Click Download ZIP from the dropdown menu
5. Find the downloaded zip file on your computer and unzip it
This should hopefully work! Now you can either edit it (by opening in vscode or other another app) or you can view it by double clicking in your files
